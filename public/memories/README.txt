MEMORIES FOLDER — Tanu
======================

Add as many photos and videos as you like (no hard limit).

Supported:
  Images: .jpg .jpeg .png .gif .webp .avif .svg .bmp
  Video:  .mp4 .webm .ogg .mov .m4v

After adding or removing files here:
  1) Run:  npm run memories:manifest
     (This is also run automatically before "npm run dev" and "npm run build".)

  2) Deploy the built site — files in this folder are copied to production.

The app reads public/memories/manifest.json (auto-generated). Do not edit manifest.json by hand.
